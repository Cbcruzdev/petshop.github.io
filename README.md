# Amigo Pet — Fase 1

Projeto acadêmico da disciplina Fundamentos de Sistemas Web.

- Página inicial com identificação do petshop e navegação.
- Página de produtos com três categorias:
  - Acessórios: 2 produtos.
  - Rações não perecíveis: 2 produtos.
  - Higiene e limpeza: 2 produtos.
- Cada produto apresenta imagem, descrição e valor.
- Página de serviços com banho e tosa:
  - Sem tele-busca.
  - Com tele-busca.
- Cada serviço apresenta descrição, valor e informação sobre tele-busca.
- Rodapé com autoria acadêmica, contato e links de navegação.


- HTML5.

Nesta Fase 1 não foram utilizados CSS, Bootstrap ou JavaScript, conforme solicitado no enunciado.
